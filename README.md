# tg-digest: персональный фильтр Telegram-каналов

Раз в день собирает посты из ваших каналов, выкидывает рекламу и дубли,
отправляет всё одним запросом в DeepSeek и присылает в Избранное короткий
дайджест: одно главное событие с объяснением "почему это важно лично вам
и что сделать", до трёх строк "стоит знать" и честное "остальные N тем
не стоят вашего времени".

## Установка на VPS

```bash
mkdir -p /opt/tg-digest && cd /opt/tg-digest
# скопируйте сюда файлы проекта (scp, git, как удобно)

python3 -m venv venv
./venv/bin/pip install -r requirements.txt

cp env.example .env
cp config.example.yaml config.yaml
nano .env           # вписать TG_API_ID, TG_API_HASH, DEEPSEEK_API_KEY
nano config.yaml    # вписать свои каналы, написать свой профиль
```

Где взять ключи:
- Telegram: https://my.telegram.org, раздел API development tools. Это ключи
  приложения, не бота. Бот здесь не нужен вообще.
- DeepSeek: https://platform.deepseek.com, раздел API Keys. Баланса в пару
  долларов хватит на месяцы.

## Первый запуск

```bash
./venv/bin/python digest.py --dry-run
```

Первый запуск интерактивный: скрипт спросит номер телефона, код из Telegram
и пароль двухфакторки, если она включена. Сессия сохранится в файл
`digest_session.session`, дальше вход не потребуется. Дайджест напечатается
в консоль без отправки, так удобно тестировать.

Когда всё нравится, запустите без флага, дайджест придёт в Избранное:

```bash
./venv/bin/python digest.py
```

Закройте права на секреты:

```bash
chmod 600 .env digest_session.session
```

Файл сессии равен полному доступу к вашему аккаунту Telegram, обращайтесь
с ним как с паролем: не коммитьте, не копируйте на чужие машины.

## Публикация репозитория

`.gitignore` уже прячет секреты: `.env`, файлы сессии `*.session`, лог и ваш
личный `config.yaml`. Профиль в конфиге это персональные данные, поэтому в
репозиторий идёт только обезличенный шаблон `config.example.yaml`. Перед
первым `git push` посмотрите `git status`: этих файлов в списке быть не должно.

## Локальный тест на Windows

PowerShell, из папки проекта:

```powershell
winget install Python.Python.3.12    # если Python не установлен
python -m venv venv
venv\Scripts\pip install -r requirements.txt
copy env.example .env
copy config.example.yaml config.yaml
notepad .env          # вписать ключи
notepad config.yaml   # каналы и профиль
venv\Scripts\python digest.py --dry-run
```

Активировать venv не нужно, обращаемся к `venv\Scripts\python` напрямую,
это заодно обходит вопросы с ExecutionPolicy. Если в консоли ломается
кириллица, добавьте флаг: `venv\Scripts\python -X utf8 digest.py --dry-run`.

Файл сессии `digest_session.session` создастся рядом со скриптом. На VPS
его переносить не нужно, там просто войдёте заново. Один и тот же файл
сессии нельзя использовать с двух машин одновременно, Telegram убивает
такую сессию с ошибкой AUTH_KEY_DUPLICATED.

Для регулярного запуска с ноутбука вместо крона есть Планировщик задач
Windows, но ноутбук должен быть включён в момент запуска, поэтому боевой
вариант всё равно VPS.

## Расписание

Крон, каждый день в 21:05 по Москве (18:05 UTC, проверьте таймзону сервера
командой `timedatectl`):

```
5 18 * * * cd /opt/tg-digest && ./venv/bin/python digest.py >> digest.log 2>&1
```

Либо задайте `CRON_TZ=Europe/Moscow` первой строкой в crontab и пишите
время по Москве.

## Дайджест в канал

По умолчанию дайджест приходит в Избранное (`target: me`). Чтобы публиковать
в канал, создайте канал и укажите в `target` его username без @, а для
приватного канала ID вида `-100XXXXXXXXXX` (покажет @getidsbot). Постит ваш
же аккаунт, поэтому он должен быть владельцем или админом с правом
публикаций. Ошибки пайплайна в канал не попадают, они всегда приходят
в Избранное.

## Калибровка (первая неделя-две)

В конфиге включён `calibration: true`: в конце дайджеста приходит список
отфильтрованных тем одной строкой с баллами. Смотрите на него и правьте:

- модель пропустила важное: допишите тему в блок "Значимо" профиля
- модель тащит мусор наверх: допишите тему в блок "Шум" или поднимите пороги

Когда неделю подряд претензий нет, ставьте `calibration: false` и читайте
только выжимку. В этом и была цель.

## Тюнинг

| Параметр | Что делает |
|---|---|
| `main_threshold` | балл, с которого тема становится "Главным". Поднимите до 7-8, если хотите главное событие реже, только по серьёзным поводам |
| `worth_threshold` | балл для блока "Стоит знать" |
| `max_worth_items` | длина блока "Стоит знать", можно поставить 0 и получать только одно главное событие |
| `target` | куда слать дайджест: `me` (Избранное), username канала или его ID |
| `hours_lookback` | окно сбора, 24 часа по умолчанию |
| `ad_patterns` | регулярки антирекламы, дополняйте под свои каналы |

## Приватные каналы

Работают, если ваш аккаунт в них состоит. В `channels` вместо username
укажите ID вида `-100XXXXXXXXXX`: перешлите любой пост канала боту
@getidsbot, он покажет ID (поле forwarded from).

## Стоимость

При 100 постах в день это примерно 20-30 тысяч входных токенов на запуск,
около миллиона в месяц. На тарифах deepseek-chat выходит меньше доллара
в месяц.

## Если дайджест перестал приходить

1. Посмотрите `digest.log` в папке проекта.
2. Telegram изредка сбрасывает сессии: зайдите на VPS и повторите
   интерактивный вход через `--dry-run`.
3. Ошибки самого пайплайна (например, кончился баланс DeepSeek) скрипт
   присылает вам в Избранное сам.
